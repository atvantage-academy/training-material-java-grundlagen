Objektorientierte Programmierung mit Java

Willkommen! In dieser Woche wechselst Du vom prozeduralen Denken in die objektorientierte Welt von Java — Schritt für Schritt, vom ersten Programm bis zum kleinen eigenen Projekt.

  • Kursbeschreibung

Übungen

Die Übungen bauen aufeinander auf. Der Auftakt an Tag 1 dient dem Ankommen in Plattform und Werkzeugen; ab Tag 2 nutzen alle Übungen das durchgängige Banking-Beispiel.

Tag 1 — Ankommen in Java

  • Die Java-Plattform erkunden
  • Visualisierung: Java-LTS-Evolution
  • Das erste Projekt in der IDE anlegen und starten
  • Prozedurale Logik nach Java übertragen

Tag 2 — Vom Prozeduralen zum Objekt

  • Klassen & Objekte
  • Kapselung & Konstruktoren
  • Objektbeziehungen & equals/hashCode

Tag 3 — Wiederverwendung & Abstraktion

  • Vererbung & abstrakte Klassen
  • Polymorphie
  • Interfaces & Abstraktion

Tag 4 — Robuste Programme

  • Ausnahmebehandlung
  • Collections
  • Generics

Tag 5 — Zusammenspiel & Praxis

  • Das Projekt mit Gradle anlegen und eine Bibliothek einbinden
  • Das Konto mit JUnit testen
  • Das Banking-System erweitern
