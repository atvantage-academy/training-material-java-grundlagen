Prozedurale Logik nach Java übertragen

Prozedurale Logik nach Java übertragen

Als Umsteiger:in möchte ich vertraute Konstrukte wie Variablen, Schleifen und Methoden in Java schreiben, damit mir die Syntax für den Rest der Woche flüssig von der Hand geht.

Hinweis: Die Visualisierung Java-Syntax auf einen Blick (rechts unter „Weiterführende Informationen“) fasst Datentypen, Schreibweisen, Typumwandlung, Methoden und Kontrollstrukturen zum Nachschlagen zusammen.

Lernziele

Die Lernenden…

  • deklarieren Variablen mit passenden primitiven Datentypen und nutzen Kontrollstrukturen in Java.
  • schreiben eine Methode mit Parametern und Rückgabewert und rufen sie auf.
  • benennen die Signatur einer Methode und überladen sie.
  • wandeln Typen bewusst um und setzen dort einen Cast, wo er nötig ist.

Definition of Done

  • Es gibt eine Methode sumCents(int[] amounts), die eine Summe berechnet und zurückgibt.
  • Eine Schleife und eine Bedingung kommen sinnvoll zum Einsatz.
  • Der Zinsbetrag wird aus einem double auf ganze Cent umgewandelt.
  • Es gibt zwei überladene Varianten von format.
  • main ruft die Methoden auf und gibt die Ergebnisse aus.
  • Du hast die Reflexionsfragen schriftlich beantwortet.

Arbeitsschritte

Eine Methode schreiben

Schreibe eine statische Methode, die ein int[] mit Cent-Beträgen aufsummiert.

static int sumCents(int[] amounts) {
  int sum = 0;
  for (int a : amounts) {
    sum += a;
  }
  return sum;
}

Hinweis: Beträge als ganze Cent (int) zu führen vermeidet Rundungsfehler von float/double — ein Muster, das später die Klasse Money aufgreift. Die Anzahl der Elemente liefert amounts.length — beim Array ohne Klammern.

Eine Bedingung ergänzen

Gib je nach Summe eine unterschiedliche Meldung aus (z. B. „im Plus” / „ausgeglichen” / „im Minus”). Probiere für den einfachen Fall auch den Bedingungsoperator ?: aus.

Den Zinsbetrag umwandeln

Berechne aus dem Saldo einen Zinsbetrag als double und wandle ihn in ganze Cent um.

final double ZINSSATZ = 0.015;
double zins = sumCents(amounts) * ZINSSATZ;
int zinsCent = (int) zins;   // schneidet ab, rundet nicht

Hinweis: Lass den Cast testweise weg und lies die Fehlermeldung des Compilers.

Die Methode überladen

Schreibe eine Methode format(int cents), die einen Betrag lesbar ausgibt, und daneben eine zweite Variante format(int cents, String waehrung), die zusätzlich die Währung anhängt.

Hinweis: Beide heißen gleich und unterscheiden sich nur in der Parameterliste — genau das ist Überladen. Ein anderer Rückgabetyp allein würde dafür nicht genügen.

Die Gültigkeit im Block ausprobieren

Deklariere eine Variable innerhalb eines if-Blocks und versuche, sie nach dem Block zu verwenden. Sieh Dir die Fehlermeldung an und behebe sie.

Reflexionsfragen

  • Was gehört zur Signatur einer Methode — und wodurch unterscheiden sich zwei überladene Methoden?
  • Warum braucht die Umwandlung von double nach int einen Cast, umgekehrt aber nicht?
  • Welche Java-Schreibweise musst Du gegenüber Deiner bisherigen Sprache bewusst anders machen?
