Prozedurale Logik nach Java übertragen

Prozedurale Logik nach Java übertragen

Als Umsteiger:in möchte ich vertraute Konstrukte wie Variablen, Schleifen und Methoden in Java schreiben, damit mir die Syntax für den Rest der Woche flüssig von der Hand geht.

Lernziele

Die Lernenden…

  • deklarieren Variablen mit passenden Datentypen und nutzen Kontrollstrukturen in Java.
  • schreiben eine Methode mit Parametern und Rückgabewert und rufen sie auf.
  • vergleichen Strings korrekt mit equals statt mit ==.

Definition of Done

  • Es gibt eine Methode sumCents(int[] amounts), die eine Summe berechnet und zurückgibt.
  • Eine Schleife und eine Bedingung kommen sinnvoll zum Einsatz.
  • Eine String-Prüfung nutzt equals (nicht ==).
  • main ruft die Methode auf und gibt das Ergebnis aus.
  • Du hast die Reflexionsfragen schriftlich beantwortet.

Arbeitsschritte

Eine Methode schreiben

Schreibe eine statische Methode, die ein int[] mit Cent-Beträgen aufsummiert.

static int sumCents(int[] amounts) {
  int sum = 0;
  for (int a : amounts) {
    sum += a;
  }
  return sum;
}

Hinweis: Beträge als ganze Cent (int) zu führen vermeidet Rundungsfehler von float/double — ein Muster, das später die Klasse Money aufgreift.

Eine Bedingung ergänzen

Gib je nach Summe eine unterschiedliche Meldung aus (z. B. „im Plus” / „ausgeglichen”).

Strings richtig vergleichen

Vergleiche eine Währungsangabe ("EUR") mit equals und beobachte den Unterschied zu ==.

Hinweis: == prüft, ob es dasselbe Objekt ist; equals prüft den Inhalt. Für Textvergleiche willst Du fast immer equals.

Reflexionsfragen

  • Worin unterscheidet sich ein primitiver Typ (int) von einem Referenztyp (String)?
  • Warum kann == bei Strings zu überraschenden Ergebnissen führen?
