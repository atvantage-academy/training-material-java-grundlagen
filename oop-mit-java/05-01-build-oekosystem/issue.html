Das Projekt bauen und eine Bibliothek einbinden

Das Projekt bauen und eine Bibliothek einbinden

Als Entwickler:in möchte ich Abhängigkeiten deklarativ verwalten, damit mein Build reproduzierbar ist und ich fremde Bibliotheken ohne manuelles Kopieren nutzen kann.

Lernziele

Die Lernenden…

  • bauen das Projekt mit dem Build-Werkzeug (Gradle/Maven) reproduzierbar.
  • deklarieren eine externe Abhängigkeit in der Build-Datei.
  • nutzen eine Klasse der eingebundenen Bibliothek im eigenen Code.

Definition of Done

  • Das Projekt baut mit einem einzigen Build-Befehl.
  • In der Build-Datei (build.gradle/pom.xml) ist eine neue Abhängigkeit deklariert.
  • Eine Klasse der Bibliothek wird im Code verwendet und das Programm läuft.
  • Du hast die Reflexionsfragen schriftlich beantwortet.

Arbeitsschritte

Das Projekt bauen

Baue das Banking-Projekt und stelle sicher, dass der Build grün ist.

./gradlew build

Eine Abhängigkeit deklarieren

Ergänze in der Build-Datei eine kleine, nützliche Bibliothek (z. B. Apache Commons Lang) im dependencies-Block.

dependencies {
    implementation 'org.apache.commons:commons-lang3:3.14.0'
}

Hinweis: Nach dem Ändern der Build-Datei muss das Projekt neu synchronisiert/gebaut werden, damit die IDE die Bibliothek kennt.

Die Bibliothek verwenden

Nutze eine Methode der Bibliothek an einer sinnvollen Stelle (z. B. StringUtils.isBlank(...) bei der Kunden-Validierung).

Reflexionsfragen

  • Warum ist es besser, Abhängigkeiten zu deklarieren, statt .jar-Dateien manuell abzulegen?
  • Was gehört in die Versionsverwaltung — die Bibliotheken selbst oder die Build-Beschreibung?
  • Was könnte passieren, wenn zwei Bibliotheken unterschiedliche Versionen derselben Abhängigkeit verlangen?
