Standard-Button der Marke: Anthrazit `#343E3F`, weißer Text, Radius 5px, Hover `#4D5657`; auf dunklen Sektionen `variant="inverted"` (weiß, Slate-Text, Hover transparent mit weißem Rahmen, Radius 8px).

```jsx
<Button onClick={...}>Jetzt beraten lassen</Button>
<Button variant="inverted">Mehr dazu</Button>
```

Props: `variant` (primary|inverted), `size` (sm|md|lg), `disabled`.
